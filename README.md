# Stream Voice Marker

Локальный плагин Adobe Premiere Pro 25.x для Windows: поиск голоса стримера, цветная разметка длинных реплик и Jump Cut.

## Возможности

- Сохранённые профили голоса на базе SpeechBrain ECAPA-TDNN и Silero VAD.
- Объединение реплик с паузами до 30 секунд и фильтр моментов с более чем 40 секундами найденной речи; параметры настраиваются.
- Jump Cut по средней громкости за 20 мс в каждом аудиоканале.
- Синхронная обработка V1/V2/аудио с сохранением кадрирования и эффектов клипов.
- Создание новой последовательности или применение внутри текущего эпизода.
- Сохранение исходных позиций отдельных выбранных моментов и связывание фрагментов видео/аудио.
- Экспериментальная упаковка каждого момента в цельные отдельные клипы V1/V2/аудио.
- Автоматическое сохранение настроек и кэширование анализа.

## Установка

Нужны Premiere Pro 25.x, Python 3.10–3.12, FFmpeg и FFprobe в PATH.

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -PythonExe 'C:\path\to\python.exe'
```

Установщик создаёт локальное окружение Python, копирует CEP-панель и включает `PlayerDebugMode=1` для Adobe CSXS.12. Этот режим разрешает загрузку неподписанных CEP-расширений. Первичная загрузка зависимостей и моделей требует интернета; анализ выполняется локально на CPU.

Откройте в Premiere **Окно → Расширения → Stream Voice Marker**. Не перемещайте папку проекта после установки: runtime-конфигурация использует абсолютные пути. Для обновления: `powershell -ExecutionPolicy Bypass -File .\install.ps1 -SkipDependencies`.

## Первый запуск

Личные профили голоса, исходные записи, модели и результаты анализа в репозиторий не включены.

1. Выберите исходное видео и нажмите «Взять выделенный клип».
2. Откройте «Другой голос / свои образцы». Укажите чистые фрагменты голоса по 3–60 секунд, используя время от начала файла.
3. Сохраните профиль, затем нажмите «Найти речь».
4. После анализа настройте отбор и создайте размеченную последовательность. Изменение фильтров через «Пересчитать отбор» использует кэш.

Для Jump Cut выделите видеоклипы, рассчитайте удаляемые паузы и выберите создание новой последовательности либо применение в текущей. Второй вариант изменяет исходный монтаж; при ошибке возможны частичные изменения, отменяемые командами Premiere.

## Ограничения

Jump Cut поддерживает клипы одного файла с обычной скоростью и синхронным исходным звуком. Выбранные наложенные видеослои должны совпадать по границам и исходному времени. Дополнительная музыка, несколько аудиопотоков, переходы и заблокированные заполненные дорожки не поддерживаются. Детектор использует исходный звук до аудиоэффектов и регулировки громкости.

Экспериментальной упаковке нужны пустая разблокированная видео- и аудиодорожка. На основном таймлайне остаются отдельные цельные V1/V2/аудио; склейки находятся внутри служебных вложенных эпизодов. Не удаляйте эти эпизоды. Для повторного анализа используйте исходные клипы или откройте вложенный эпизод.

Распознавание голоса и тишины требует подбора порогов под запись. Настройки эффектов микшера и все комбинации монтажа не проверены. Некоторые операции используют внутренний QE API Premiere и зависят от версии приложения.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node tests/jump-layout.cjs
node tests/jump-inplace.cjs
node --check cep/panel.js
```

Браузерный smoke-тест: `node tests/panel-smoke.cjs <путь-к-модулю-playwright>`. Он использует Microsoft Edge и имитирует границы CEP. Для проверки реального монтажа нужен запущенный Premiere.

## Структура

- `cep/` — панель и ExtendScript.
- `backend/` — распознавание голоса, обнаружение тишины, планы монтажа.
- `profiles/` — локальные профили (игнорируются Git).
- `tests/` — автоматические проверки.
- `data/` — локальные модели, кэш и результаты (игнорируются Git).

`cep/vendor/json2.js` — JSON-js Douglas Crockford, public domain. Зависимости и веса моделей распространяются на условиях их правообладателей.
